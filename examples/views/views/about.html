About dex Template Engine

Built directly into the core framework using only the D standard library (Phobos).

Key Highlights:

  • Zero Dependencies: No third-party template packages or external parsers needed.
  • Handlebars/Mustache Syntax: Familiar {{var}}, {{#if}}, {{#each}}, and {{> partial}}.
  • Fast Automatic XSS Escaping: All variables are HTML-escaped by default, with raw output enabled via {{{raw}}}.
  • Strongly-Typed Integration: Pass any D struct or class directly into res.render("view", myStruct).
  • Thread-Safe AST Caching: Enable app.cacheViews = true in production for fast zero-disk-IO rendering.
