dex File & Media Server

Demonstrating serveStatic and chunked res.sendFile with HTTP Range (206 Partial Content) streaming support.

Static Assets Served via serveStatic()

  • /styles.css (CSS with Cache-Control)
  • /sample.txt (Plaintext file)
  • /media.txt (Simulated streamable asset)

Download Endpoints via res.sendFile()

Streamed in 64 KiB chunks with Accept-Ranges: bytes:

  • Download sample.txt (attachment)
  • Download media.txt (attachment)
  • GET /api/files (JSON Metadata)
