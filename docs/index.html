Why dex

Small API. Serious plumbing.

Everything a JSON API needs, and nothing you have to fight.

Express-shaped routing

Methods, :params, wildcards, route chains, and case-insensitive matching. HEAD falls back to GET.

app.get("/users/:id", handler)

Middleware that composes

Plain delegates, next() for flow, next(err) for failures. Mount routers under a prefix and keep handlers small.

app.use("/api", auth)

JSON in, JSON out

Parsed JSON, form, and text bodies. Query parameters and cookies are ready before your handler runs.

res.json(user)

A server in the box

HTTP/1.1 keep-alive, chunked requests, 100-continue, socket timeouts, and request limits without another dependency.

app.listen(3000)

Static files, guarded

serveStatic handles MIME types, index files, cache headers, and rejects traversal and symlink escapes.

app.use(serveStatic("./public"))

Point Dub at the dex checkout, write a handler, run it. No code generation, no config files, no hidden runtime.

import dex;

Middleware

Compose behavior, not boilerplate.

Handlers are plain delegates. Middleware calls next(), errors travel to error middleware, and mounted routers keep paths clean.

app.d 
app.use(logger());

app.use("/api", (req, res, next)
{
    if (req.get("authorization") is null)
    {
        res.status(401).send("Unauthorized");
        return;
    }
    next();
});

app.use((Throwable err, Request req,
         Response res, Next next)
{
    res.status(500).json(["error": err.msg]);
});

next() and next(err)

Continue the chain, short-circuit with a response, or send failures straight to error middleware.

Routers mount routers

app.use("/api/v1", api) strips the prefix, merges params, and exposes the mount in req.baseUrl.

Status-aware errors

Throw new HttpError(404, "Not found"). The default handler maps it to the right status and a readable body.

Need auth or CORS? The auth + CORS example has both as copyable middleware.
